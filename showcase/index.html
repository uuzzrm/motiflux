Motiflux V1 is an AI skill for source-aware logo motion: the source image stays recognizable while the selected theme changes the reveal choreography.

The HTML includes portable GIF outputs plus interactive players. The PDF is a static storyboard of the same image-to-animation sequences. Public design systems are principle analogues only; no private vendor recipe is claimed.
